# Notes App

## Anggota Kelompok

1. Chelsy Ramadhani

## Deskripsi

Notes App adalah aplikasi catatan sederhana yang dibuat menggunakan Flutter dan Dart. Aplikasi ini digunakan untuk menambah, melihat, mengedit, dan menghapus catatan.

## Fitur

- Menambah catatan
- Melihat daftar catatan
- Mengedit catatan
- Menghapus catatan
- Validasi input kosong
- Penyimpanan catatan secara lokal menggunakan Hive

## Teknologi

- Flutter
- Dart
- Hive
- Flutter BLoC (Cubit)

## Cara Menjalankan

1. Jalankan `flutter pub get`.
2. Jalankan aplikasi menggunakan perintah `flutter run -d web-server --web-port=7357`.
3. Buka alamat lokal yang muncul di terminal.

## Penyimpanan Data

Data catatan disimpan secara lokal menggunakan Hive sehingga catatan tetap tersedia ketika aplikasi dibuka kembali pada lingkungan penyimpanan yang sama.
